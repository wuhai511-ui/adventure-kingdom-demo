# 冒险王国 Demo

儿童任务积分奖励游戏化教育小程序原型

## 在线访问
部署后替换为你的 Vercel 链接：
`https://adventure-kingdom.vercel.app`

## 本地预览
```bash
npx serve .
```

## 部署到 Vercel

### 方式一：拖拽部署（最快，30秒）
1. 打开 https://vercel.com → 登录（GitHub 账号）
2. 点击 **"Add New"** → **"Project"**
3. 找到 **"Deploy without Git"** 或直接拖拽本文件夹到页面
4. 等待 10 秒 → 得到 `xxx.vercel.app` 链接

### 方式二：Git 部署（可更新）
1. 在 GitHub 新建仓库，上传本文件夹所有内容
2. Vercel → "Add New Project" → 选择该仓库
3. Framework Preset 选 **"Other"**
4. 点 Deploy → 得到链接

## 更新 Demo
修改 `index.html` 后重新部署即可，Vercel 会自动生成新链接（旧链接仍可用）
